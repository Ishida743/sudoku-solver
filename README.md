# Sudoku Solver

Pythonで実装した数独ソルバーです。

## 概要

数独を自動で解くプログラムです。
単純な総当たりではなく、制約伝播と探索アルゴリズムを組み合わせて解を探索します。

## 使用した手法

- Naked Single
- Hidden Single
- MRV（Minimum Remaining Values）
- バックトラッキング

Naked Single / Hidden Singleによる制約伝播で確定できるマスを埋め、
確定できない場合はMRVを用いて候補数が最も少ないマスから探索します。

## 実行時に計測する項目

- 実行時間
- 探索ノード数
- バックトラック回数
- 最大メモリ使用量

## 使用技術

- Python 3
- `time.perf_counter`
- `tracemalloc`

## 実行方法

```bash
python sudoku_solver.py
```

## 工夫した点

単純なバックトラッキングだけで探索するのではなく、制約伝播とMRVを組み合わせることで探索範囲を減らすよう工夫しました。

また、実行時間だけでなく探索ノード数、バックトラック回数、最大メモリ使用量を計測できるようにし、アルゴリズムの性能を確認できるようにしました。
